# Handoff 2026-11-15

## Goal
Flag-only LLM spelling/grammar language server for Zed (Markdown, LaTeX,
Typst), then a benchmark for the owner's IEEE paper. Owner writes the paper;
Claude writes the tool.

## State

  name; not on crates.io and should not be until the name is chosen.
- Server (Rust, tower-lsp-server): segmentation + mask for all three
  languages, quote anchoring, reason sanitizer, Anthropic / OpenAI-compatible
  / mock backends, paragraph-hash cache, debounce, context snapshot for
  prompt caching, voting, ignore / add-word code actions, JSONL log,
  `flagcheck check FILE` CLI. 31 unit tests pass.
- Verified here: LSP round trip over stdio with the mock backend (UTF-16

- Not verified: a real Claude call (no key on andples-oma), and Zed on the
  Mac. Zed extension compiles to wasm32-wasip2.

## Decisions (why)
- Raw source to the model, mask applied afterwards: deterministic and
  testable; the model still sees markup as context.
- Cache keyed by paragraph text + settings fingerprint: also solves stale
  results (old text matches no current paragraph).
- Context snapshot refreshed only after 4 min or >20 % paragraph drift, so
  the cached prefix stays byte-identical between checks.
- Default effort `low`, adaptive thinking: latency.
- Display maths masks but does not split paragraphs (it sits in sentences).
- Flags from an edited paragraph are carried over (quote still present on a
  word boundary) until it is re-checked: no blinking underlines.
